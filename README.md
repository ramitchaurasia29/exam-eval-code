# Exam Evaluation Platform

An AI-assisted exam evaluation and grading workflow application built with React, Vite, Tailwind CSS, and TypeScript.

## Features

- **Admin & Teacher Portals**: Manage assessments, question papers, rubrics, and answer keys.
- **Answer Sheet Review & AI Grading**: Review digitized booklets, side-by-side rubrics, AI feedback, and audit logs.
- **Bulk Upload & Processing Queue**: Streamlined scan upload and processing pipeline.
- **Student & Parent Result Portals**: Dedicated result viewing interfaces.

## Tech Stack

- **Frontend**: React 18, React Router v6, TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Charts**: Recharts
- **Build Tool**: Vite

## Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
